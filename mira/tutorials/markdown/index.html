Why Markdown Still Rules in 2026

Markdown remains the lingua franca of technical writing, documentation, blogs, READMEs, notes, newsletters, Obsidian vaults, Notion exports, GitHub issues, Discord messages, and increasingly – full websites via MDX.

MDX = Markdown + JSX
→ Write Markdown, embed React components, use syntax highlighting, and still get static HTML output.

1. Basic Text Formatting

**bold**   or __bold__
*italic*   or _italic_
***bold italic***
~~strikethrough~~
==highlight==          (not everywhere – GitHub yes, many renderers no)

11. Best Practices & Gotchas 2026

  • Use consistent list markers (- or *)
  • Always specify language in code blocks for highlighting
  • Prefer reference-style links for long documents
  • Test footnotes & tables in your renderer
  • For MDX: keep frontmatter simple (title, description, date, image)
  • Avoid too deep nesting in lists (>3 levels → hard to read)
  • Use > [!NOTE] / > [!TIP] / > [!WARNING] callouts
> [!TIP]
> This is a tip callout – very useful in docs!
